# 🛒 E-Commerce Mobile Application (Flutter)

## 📌 Overview
This project is a full-featured e-commerce mobile application built using Flutter.  
It focuses on delivering a smooth and user-friendly shopping experience, with scalable architecture and clean code practices.

The application is currently under active development, with ongoing improvements and new features being added.

---

## 🚀 Current Features
- Browse products with a clean and modern UI
- Search for products quickly and efficiently
- Filter products by category, price, and ratings
- Sort products (price, rating, etc.)
- View detailed product information (description, reviews, ratings)
- Responsive design across different screen sizes
- Integration with REST APIs for real-time data

---

## 🧠 Technical Approach
- Flutter & Dart
- Clean Architecture
- BLoC (State Management)
- REST API integration
- Scalable and maintainable code structure

---

## 🔮 Future Improvements
- User authentication (Login / Register)
- Shopping cart (add / remove / update items)
- Order management system
- Admin panel for managing products
- Offline mode using local database
- Performance optimization and caching
